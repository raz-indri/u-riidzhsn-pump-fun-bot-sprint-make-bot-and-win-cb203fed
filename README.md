Tidehunter: an early-momentum pump.fun replay bot. It snipes coins whose first minutes show buy-dominated flow from several distinct wallets and a price already lifting off launch, sizes each buy by the 1%-of-real-reserves cap (0.02 SOL first tranche, 0.03 SOL added only into a winner up 15%), and exits on a ladder — half at +18%, the rest at +45%, a trailing stop past +30%, a hard stop at -5% and a time stop for coins that go nowhere.

## Run it

```sh
PYTHONHASHSEED=0 python3 -P -s main.py
```
